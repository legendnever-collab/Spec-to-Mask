# 1.6T 아키텍처 — 3A+ DR8 변조기 선택 (Phase B)

기준: `main` fa9f16a (PR #2 병합 직후). 3A+ 레벨 안에 **변조기 선택** 손잡이를 넣었습니다. 기본값은 MZM ×8(2-3 TW-MZM)이고, MRR ×8(2-3R 링)을 고를 수 있습니다. 레벨 스펙, 기존 진행 기록, MZM 결과는 바뀌지 않았습니다.

## 1. 결정과 근거

| 질문 | 결정 | 근거 |
|---|---|---|
| 링 변조기를 어느 1.6T 아키텍처에? | **3A+ DR8만** | DR8은 레인마다 광섬유가 따로이고 파장이 하나입니다. 8개 링이 각자 같은 파장에서 독립적으로 동작하므로, 링끼리 공진을 나누거나(공진 배정) 버스를 공유하며 생기는 크로스토크·FSR 별칭이 없습니다. 링에 남는 문제는 레인별 히터·락과 레이저 드리프트 추적입니다. |
| 3A (2×FR4)에도? | **MZM 유지** | FR4는 CWDM 4파장을 한 광섬유에 묶습니다. 링 송신기로 만들려면 링이 파장마다 다른 공진을 맡고 링 Mux를 쓰는 WDM 링 Tx가 되어야 합니다 — Phase E(WDM8)의 문제이며, DR8 숫자만 바꿔 흉내 내지 않습니다. 이 아키텍처는 별도 레벨 **3W**로 구현했습니다([wdm8.md](wdm8.md)). |
| 스펙은? | **MZM 기준 그대로** | 변조기는 레벨 안의 아키텍처 선택입니다. `tools/calibrate_s3.js`는 계속 MZM 조합만으로 ★/★★ 예산을 정하고, MRR이 그 예산에 닿는지는 보고만 합니다(스펙 불변). |
| 기존 설계·진행 | **호환** | `mod` 키가 없는 저장 설계는 MZM으로 열립니다. MZM 경로는 fa9f16a와 비트 단위로 같습니다(`test/t_dr8.js`). |

## 2. 모델

### 2.1 광 경로 (두 변조기 공통)

```
P_mod(T) = P_las − derate(T) − (SSC + 결합) − TPA(P_chip) − [10 log N + 분기 과잉손실 · log₂N]
OMA(T)   = P_mod(T) + G_mod
수신     = OMA − SSC − 채널 − SSC − FAU(CPO)
마진     = 수신 − (페널티_mod + RIN + 전기 페널티) − 감도
```

두 변조기는 같은 빛(P<sub>mod</sub>)을 받습니다. 바뀌는 것은 G<sub>mod</sub>(= OMA<sub>outer</sub>/P<sub>mod</sub>, 삽입 손실 포함), 눈 페널티, 전력 항목입니다.

### 2.2 MRR 레인

| 항목 | 식 / 방법 | 충실도 |
|---|---|---|
| 링 설계 | 2-3R 카드(카드 사용 시) 또는 2-3R 기준 설계. 레이아웃 반경은 2-3R에서 13 dBm 입력으로 정해진 그 반경(그려진 부품) | Physics-informed Surrogate |
| 광학 | 2-3R 엔진(`KINDS.mrr._x.analyse`)을 **모듈의 P<sub>mod</sub>**에서 다시 계산 — 자기 가열·TPA·CMT×RC 눈·5-tap FFE. 0.5 dB 격자에서 계산하고 그 사이는 선형 보간(오차 < 0.05 dB, 테스트) | Physics-informed Surrogate |
| 락 | 레인마다 히터가 공진을 설계 디튜닝 x에 잡아 둡니다 → 광학은 온도에 무관 | Analytical |
| 히터 (레인당) | P<sub>h</sub>(T) = {[λ<sub>op</sub> + Δλ<sub>L</sub>(T) − λ<sub>r,unheated</sub>(T, P<sub>mod</sub>)] mod FSR} × P<sub>2π</sub>/FSR, 0–70 °C 15점의 최댓값을 모듈 전력에 | Physics-informed Surrogate |
| 레이저 드리프트 | 비냉각: Δλ<sub>L</sub> = (dλ<sub>DFB</sub>/dT)(T − 25 °C), dλ<sub>DFB</sub>/dT = 0.085 nm/K(1310) · 0.10 nm/K(1550). TEC: 0 | Unverified Assumption |
| 열 안정 | 2-3R의 자기 가열 개루프 이득 g<sub>th</sub>를 각 코너의 P<sub>mod</sub>에서. g<sub>th</sub> ≥ 1 → 링크 불가(★·Fab 실패) | Physics-informed Surrogate |
| 드라이버 | MZM과 같은 드라이버 IC 등급(패키지별 대표값) − 부하 에너지 차 × 224 Gb/s. 부하: MZM 종단 선로 2·V<sub>rms</sub>²/R<sub>T</sub>(2-3 기준 설계) vs 링 PAM4 C·V² | Unverified Assumption |
| 락 제어 | 모니터 PD + DAC, 레인당 2 mW | Unverified Assumption |
| Fab Run | 링 광학은 공칭 공정 + 모듈 공통의 ±0.3 dB 변조 산포(MZM과 같은 처리). 다이의 폭·두께 오차 → 공진 이동(선형 감도, 전체 모델 대비 오차 < 3 %) → 히터. 레이저 파장 산포 σ 0.5 nm(가정) | Physics-informed Surrogate |

MZM 레인은 바뀌지 않았습니다: G<sub>mod</sub>·페널티는 2-3 카드(또는 기준 설계), 바이어스 히터는 레인당 평균 7.5 mW(균형 팔, 온도 무관).

### 2.3 링 열 효율과 그 민감도

히터 전력과 자기 가열은 같은 열 컨덕턴스 G′(2-1 히터 단면의 2D 유한체적 해석)를 링 둘레에 적용해 구합니다. 3D 퍼짐·리드 열손실을 빼므로 낙관적입니다.

| 조건 | 모델 | 문헌 |
|---|---|---|
| 격리 없음, h 1–2 µm, R 12 µm (Si 1310) | 142–181 pm/mW | 73–160 pm/mW (Yuan 2024; Huang 2026, 격리 없는 링) |
| 게임 기준 링: R 6.1 µm, 트렌치 격리, h 0.4 µm (Si 1310) | 547 pm/mW | 작은 링·트렌치 격리 → 더 높은 효율이 맞지만 3D 손실로 실제는 이보다 낮을 수 있음 |

열 효율을 문헌값으로 낮추면(G′를 키우면) 히터는 늘고 자기 가열은 줄어듭니다. 같은 엔진에서 G′만 바꿔 계산한 Si 1310 결과 (3A+ 기준 설계, 변조기만 MRR, `KINDS.xcvr._x.thermalSens`):

| 링 열 효율 | 링 히터 (레인, 0–70 °C 최악) | 자기 가열 ΔT (모듈, 아래 정의) | MRR 모듈 전력 (CPO 1:1 비냉각) | MZM 모듈 전력 |
|---|---|---|---|---|
| 모델 547 pm/mW | 12.4 mW | 61.0 K | 4.50 W | 4.49 W |
| 160 pm/mW | 58.8 mW | 17.8 K | 4.91 W | 4.49 W |
| 73 pm/mW | 137 mW | 8.1 K | 5.61 W | 4.49 W |

**자기 가열 ΔT의 정의.** 링 도파로 코어의 평균 온도 상승 ΔT = P<sub>abs</sub>/(G′·L) — P<sub>abs</sub>는 링에서 떨어진 광 전력 중 FCA·TPA로 흡수되는 몫을 PAM4 4레벨로 평균한 값(열 시상수 ≫ 심볼, 정상 상태), G′는 2-1 히터 단면의 2D 열 컨덕턴스, L은 링 둘레입니다. 칩 온도나 접합 최고 온도가 아니며 히터 가열분은 포함하지 않습니다. 모듈 값은 **70 °C 코너의 변조기 입력 P<sub>mod</sub>**에서 계산합니다 — Si 1310 기준 설계에서 P<sub>mod</sub> = 10.80 dBm이고, 링 광학의 0.5 dB 입력 격자(§2.2) 중 가까운 점인 **11.0 dBm**의 값이 표시됩니다(P<sub>abs</sub> 7.12 mW → 61.0 K; 정확히 10.80 dBm에서는 58.1 K).

**97 K는 어디서 왔나 (Phase B 문서 오류, v1.0 최종 패치에서 정정).** Phase B(bb74e31) 문서의 97 / 29 / 13 K는 같은 링을 **2-3R 레벨 단독 조건인 13 dBm 버스 입력**에서 계산한 값(P<sub>abs</sub> 11.38 mW → 97.4 K)과 그것을 효율 비로 줄인 값이었습니다. 같은 표의 히터·모듈 전력은 모듈의 P<sub>mod</sub> 조건이라 한 표 안에서 계산점이 섞여 있었습니다. Phase B 엔진(bb74e31)을 다시 돌려도 모듈 값은 61.0 K이므로 엔진은 바뀌지 않았고, 표의 자기 가열 열만 틀렸습니다. 2-3R 레벨 화면의 자기 가열(13 dBm 입력)과 3A+ 비교 패널의 자기 가열(모듈 P<sub>mod</sub>)이 다른 것은 입력 파워가 달라서입니다.

| 플랫폼 | P<sub>mod</sub> (70 °C) → 격자점 | 모듈 ΔT (표시) | 정확한 P<sub>mod</sub>에서 | 2-3R 단독 (13 dBm) |
|---|---|---|---|---|
| Si 1310 | 10.80 → 11.0 dBm | 61.0 K | 58.1 K | 97.4 K |
| Si 1550 | 12.75 → 12.5 dBm | 78.2 K | 82.9 K | 87.8 K |
| SiN 1310 (이종 Si 링) | 10.97 → 11.0 dBm | 42.9 K | 42.6 K | 69.5 K |
| SiN 1550 (이종 Si 링) | 12.91 → 13.0 dBm | 88.8 K | 86.9 K | 88.8 K |

ΔT는 G′에 반비례하므로 160 / 73 pm/mW 행은 Nominal 값 × (효율 / 547)과 일치합니다(61.0 × 160/547 = 17.8 K). 격자점 표시는 화면 표시용 근사로 히터·루프 이득·마진 계산에는 쓰이지 않습니다(그 값들은 정확한 P<sub>mod</sub>에서 계산하거나 격자 사이를 보간).

→ **결론은 링 열 격리에 달려 있습니다.** 모델 효율에서는 두 변조기의 모듈 전력이 거의 같고, MRR은 높은 변조 이득으로 마진(또는 레이저 공유)에서 앞섭니다. 격리 없는 링의 문헌 효율이면 MRR은 0.4–1.2 W를 더 씁니다(Si 1310·SiN 1550 기준). 비교 패널은 이 효율을 함께 보여 줍니다.

읽는 법:
- **같은 아키텍처**에서는 모듈 전력이 거의 같습니다. 링 히터(+)와 드라이버 부하(−)가 상쇄되고, 둘 다 DSP·레이저·TIA에 비해 작습니다.
- MRR의 이점은 **변조 이득**(링 −7.0 ~ −7.7 dB vs TW-MZM −8.6 ~ −10.1 dB)입니다. 그 마진으로 레이저를 더 많은 레인이 나눠 쓰면(1:2, 1:4) 모듈 전력이 줄어듭니다.
- **TEC로 레이저를 고정하면** 링 히터가 링 드리프트 전체를 맡아 커집니다(Si 1550: 8.6 → 25 mW/레인). 비냉각 DFB는 링과 같은 방향으로 움직여 히터 부담을 줄입니다.
- 링 히터는 입력 파워에도 의존합니다. 레이저 공유로 P<sub>mod</sub>가 낮아지면 자기 가열이 줄어 링이 더 파랑 쪽에 머물고, 그만큼 히터가 더 일합니다.
- 기준 링은 파랑 쪽 디튜닝이라 모든 조합에서 열적으로 안정합니다(g<sub>th</sub> < 0). 빨강 쪽 디튜닝 카드를 고출력에서 쓰면 열 폭주로 ★를 잃습니다(테스트).
- 위 결론은 §2.3의 열 효율 가정에 민감합니다.

## 4. 게임 화면

- 3A+ 파라미터 맨 위 **변조기 (레인당)**: MZM ×8 / MRR ×8.
- MRR을 고르면 목표에 "링 열 안정" 항목이 생기고, 송신 블록·메타·힌트에 링 히터·이득·락을 표시합니다.
- **같은 DR8 아키텍처에서 MZM ×8 vs MRR ×8** 패널: P<sub>mod</sub>, 이득, 페널티, 마진, 히터, 드라이버, 제어, 모듈 전력·pJ/bit, 열 안정, 링 열 효율, 레이저 파장 허용, ★/★★, (버튼) Fab 수율. 점수에는 들어가지 않습니다.
- 학습 가이드 3A+: 변조기 파라미터 행, DR8 링 식, 모델 한계 2행.

## 6. 한계

- 링 열 효율: 2D 단면 G′ × 둘레 (§2.3). 3D 열해석과 측정으로 보정해야 합니다.
- 레인 사이 공정 산포는 없음 — 한 다이의 8개 링은 같은 공정 이동을 받습니다. 실제 레인별 산포는 히터 최악값을 키웁니다.
- 레인 사이 열 크로스토크 없음 (DR8 링 간격이 충분하다고 가정).
- 락 루프 동특성(기동·온도 과도·패턴 의존 자기 가열) 없음 — 정상 상태.
- DFB 드리프트, 파장 산포, 락 전력, 드라이버 등급은 대표값 가정입니다.
- 링 구동 스윙(2-3R 기준 V<sub>pp</sub> 최대 3 V)이 패키지별 드라이버로 가능한지는 따지지 않습니다.
- CPO 외부 광원(ELS)의 온도는 케이스 온도와 같다고 둡니다(기존 3A+ 레이저 모델과 같은 가정).
