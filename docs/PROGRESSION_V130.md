# Progression Controller

Schema: additive `smq3-studio.journey`, `smq-journey/1`, by platform with separate Tutorial and MZM workspaces. A workspace holds designs, bench conditions, budget assumptions, revision, identity, introduced/practice/evidence/completed maps, protected Original and snapshots.

Each explicit Verify samples the current existing engine. No saved numeric PASS is trusted without recalculation. Evidence captures dependency fingerprint, source/model, current design identity/revision, calculation and objective status. Next always reevaluates synchronously; malformed drafts fail closed before rAF.

Dependency groups: Target (baud/modulation); PN (2-2 including bias); RF/EO (PN + 2-3 + bench); Eye (RF/EO); Budget (Eye + 2-5 + channel/coupling/sensitivity assumptions); Improve and Final (all). PN changes invalidate PN and later; MZM/bench changes invalidate RF/EO and later; Laser/loss assumptions invalidate Budget and later. Target changes invalidate all Chapter 1 evidence. Completed concept/practice remains learning history, but model evidence becomes STALE. Revisiting earlier steps keeps all values. Final Verify rebuilds engineering evidence for the current revision only after prerequisite practice has been completed.

The learner may revisit unlocked steps. No future step can be selected before predecessor completion. When a prior model result becomes stale the learner can re-verify the affected earlier steps, or after completing the sequence re-evaluate the current design at Improve/Final; earlier completed practice must exist. A changed design is never auto-completed by preview or navigation.

Solution preview: read-only numerical example. Explicit Apply: snapshot, first Original protection, real evaluate; practice credited only, no evidence PASS. Restore Original: recover full Chapter design/conditions, invalidate affected evidence. Advanced selection suspends main journey; returning resumes same chapter and step.
