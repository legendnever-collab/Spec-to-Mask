# v2 Language Policy

2026-10-18 · 사용자가 P1 진행과 함께 확정했습니다.

**기술 용어는 English로 유지하고, 설명·질문·서술어는 한글로 작성합니다.**

| 대상 | 작성 원칙 / 예시 |
|---|---|
| Parameter / KPI | Bend Radius, Bend Radiation Loss, Propagation Loss, Footprint, Vπ, Optical Budget을 사용합니다. |
| 질문 | “Bend Radius가 작으면 왜 Loss가 커질까요?”처럼 작성합니다. |
| Discovery | “Bend Radius를 늘리면 Bend Radiation Loss는 줄지만 Footprint는 커집니다.”처럼 작성합니다. |
| Action | “Comparison 저장하기”, “Original 복원하기”, “건너뛰기”, “계속하기”처럼 작성합니다. |
| Learn Physics | 기술 용어와 Equation 기호는 English로 유지하고, 원리·가정·제한 조건은 한글로 설명합니다. |
| Model Confidence | Educational Model, External Verification 같은 이름을 유지하고 “수행하지 않았습니다”처럼 상태를 설명합니다. |
| 신규 문서 | Technical Identifier와 Path는 원문을 유지하고, 설명은 한글로 작성합니다. |

Learn Physics, Engine Overview, Discover, More 등 이미 정한 UI 이름은 유지합니다. 기존 Legacy 전체 문구와 Historical Artifact는 일괄 번역하지 않습니다. P0 Prototype은 당시 검토 자료로 보존하고, P1부터 이 원칙을 적용합니다.
