## 3. 잘못 가르칠 수 있는 개념과 대응

| 위험 | 모델에서의 처리 |
|---|---|
| Q가 대역폭을 혼자 정한다 | 소신호 응답 = 선형화 CMT(광자 수명·디튜닝 피크) × 접합 RC 극. 공진 중심 한계 c/(2λQ<sub>L</sub>)는 참고선으로만 표시 |
| 정적 기울기가 크면 고속도 좋다 | 단계 3은 DC만, 단계 4에서 같은 설계를 시간영역 CMT로 112 GBd 구동 → 눈 페널티. 정적 OMA(정착 레벨)와 동적 OMA(파형 극값)를 분리 표시 |
| MRR이 항상 작고 전력이 낮다 | 비교에 히터(온도 범위 × 공정 몬테카를로 평균)와 MZM 바이어스 히터를 같은 열 모델로 포함 → MRR 열 에너지가 구동 에너지보다 큼을 보여 줌 |
| 디튜닝 방향은 무관 | 자기 가열(자유 캐리어 + TPA 흡수) 개루프 이득 계산 — 빨강 쪽(x > 0)은 양의 되먹임, ★★ 조건에 열적 안정 포함 |
| SiN에서도 PN 링 | SiN 플랫폼은 Si 활성층 이종 집적 가정으로 Si 리브 링을 계산 (2-2와 동일 가정, 화면에 명시) |
| 112 GBd PAM4 = 200 Gb/s | 224 Gb/s 라인 속도로 표기. 802.3dj 200G/레인 광 인터페이스(106.25 GBd, 212.5 Gb/s, FEC 포함)와 구분해 개념 노트에 명시 |

## 4. 사용자 요구 대비 변경한 점

| 요구 | 변경 | 이유 |
|---|---|---|
| Step 1 파라미터: 반경, n<sub>eff</sub>, n<sub>g</sub>, 공진 파장, FSR | 반경만 조절, 나머지는 결과로 표시 | n<sub>eff</sub>·n<sub>g</sub>는 단면이 정하는 물리량이지 독립 손잡이가 아님 |
| Step 3 "PN Junction Configuration" | 2-2 접합에 도핑 증가(decade) 손잡이 | L-/Z-형 접합은 2D 모델 없이는 근거 없는 수치가 됨. 같은 Soref–Bennett 모델로 도핑을 올리는 것은 물리적으로 일관됨 |
| 링 반경을 자유롭게 조정 | 설정 반경 → 공진 정렬 레이아웃 반경(1 nm 격자, 차수 m 고정) | 연속 반경은 공진을 임의 위치에 둠. 게임 반경 = GDS 반경 원칙을 지키면서 레이저에 공진을 맞추는 실제 설계 절차(Huang 2026의 drawn-radius 조정)와 일치 |
| 비교 화면 상시 표시 | ★ 또는 카드 이후, "비교 계산" 버튼 | 61 다이 몬테카를로 × 두 변조기라 1–2 s. 슬라이더 조작마다 돌리지 않음 |
| Design Lab GDS (Phase D) | 회로 스키마 `smq-circuit/1` 신설, `smq-design/1` 보존 | 기존 예제·테스트 호환 |
