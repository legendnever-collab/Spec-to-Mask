# Learning Objectives and Completion Gates

The complete per-step contract is in CURRICULUM_V130.md.

| State | Meaning | Does it grant Next? |
|---|---|---|
| Concept introduced | Learner answers the specific current-step check | Only with required practice/evidence |
| Practice completed | Current step has actual parameter edit or explicit Apply | Only with current model gate |
| Current design evaluated | Explicit Verify calculates from current valid inputs | Only if this step objective met |
| Engineering objective met | PN legacy t1; RF/EO valid observation; Eye raw gap > 0; budget >=0 | Yes, with prerequisites |
| Chapter completed | All required evidence is fresh, final review confirmed | Final completion only |
| External verification | No imported measurement/EM/BER evidence | Always NOT VERIFIED |

RF/EO Step teaches and verifies an actual parameter/result comparison; it does not impose an invented standard bandwidth. Final model-based PASS requires current live PN, 112 GBd PAM4, valid positive raw gap, nonnegative assumed budget and all earlier evidence. End-to-end BER is NOT VERIFIED. Reference Preview, Learn open/close, stars and cross-track records grant no state.

The PD reference sensitivity retains its original legacy noise/FFE assumptions. The chapter budget uses it as an explicitly independent receiver assumption, subtracts actual bench raw OMA and declared channel/coupling losses, and does not claim a combined BER simulation.
