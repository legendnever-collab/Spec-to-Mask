# Learning Journey UX

Default landing: Tutorial, one primary Start / Continue Learning button; Advanced / Legacy is secondary. Main header: Chapter + Step count, current mission, current result, visible Solution, Verify, Next. Revisit menu includes only introduced/unlocked steps. No 5-track selector in main journey.

Desktop: original Canvas above Live Inspect on left; Tune on right. A short mission card at top of Tune explains Understand → action → observation → success → next. Current step parameters highlighted; detailed guidance and read-only common concepts expand locally.

Mobile 320×568 and 390×844: compact header, Canvas first, compact journey KPI strip, scrollable Tune below. Inspect expands in its existing region. Learning text is scrollable in Tune, never pushes Canvas below a document. Theme switches in same HTML. Current results and gates are curriculum-specific; legacy Canvas score is labelled/hidden where it could mislead.

Common Knowledge opens a read-only dialog with role, model assumptions and contextual examples; close restores focus to the mission and changes no design, score or progress. PN, PAM4, TW-MZM, RF, Laser/PD, waveguide, DC/MMI, SSC, thermal, CWDM, routing and GDS remain accessible.

Final Review: My MZM 200G Design, actual target/PN/MZM/RF/EO/Eye/budget, explicit trade-off rationale, educational confidence; Learning Objective PASS, Model-based Design PASS/FAIL and External Verification NOT VERIFIED shown separately. Export JSON carries revision, evidence and assumptions. Chapters 2–4 appear as Preview only with no Start/Complete actions.
