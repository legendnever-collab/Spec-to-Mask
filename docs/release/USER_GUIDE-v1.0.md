# SPEC-to-MASK Quest v1.0 — 사용자 가이드 (사내 교육용)

광소자 하나에서 1.6T 광엔진, 그리고 GDS 레이아웃까지 **설계 결정을 직접 내리며** 배우는 학습 프로그램입니다. 계산은 물리 기반 모델이며, 결과마다 근거(해석식·근사·문헌값·가정·미검증)를 함께 보여 줍니다. 제조 준비(Tape-out)를 검증하는 도구가 아닙니다.

## 1. 시작하기
1. `spec-to-mask-v1.0.html` 파일 하나를 브라우저(Chrome·Edge 최신)로 엽니다. 설치·인터넷 연결·Python이 필요 없습니다 (릴리스 HTML은 외부 글꼴도 요청하지 않음).
2. **Stage 0**: 파장(1310 O-band / 1550 C-band)과 코어 물질(Si 220 nm / SiN 400 nm)을 고릅니다. 진행 기록은 플랫폼별로 따로 저장됩니다. 1.6T 트랜시버 학습은 Si · 1310이 표준 조합입니다.
3. 처음이면 **처음 안내**(4쪽)가 열립니다. 학습 경로를 고르거나 자유 탐색을 선택하세요. 나중에 경로 막대의 “처음 안내”로 다시 볼 수 있습니다.

## 2. 학습 경로 (권장 순서 — 언제든 자유 탐색 가능)
| 경로 | 대상 | 순서 |
|---|---|---|
| A · PIC Fundamentals | PIC 입문자 | 1-1 도파로 → 1-2 방향성 결합기 → 1-5 3-dB 커플러 → 1-7 MZI(CWDM) → 2-3 TW-MZM |
| B · Optical Engine Architect | Optical System · Packaging | 2-3 MZM → 2-3R MZM vs MRR → 3A+ DR8 → 3W WDM8 → 2-5 링크 버짓 |
| C · PIC Design Challenge | PIC 설계 | Design Lab M1 회로도 → M2 배치 → M3 배선 → M4 전기 → M5 검증 → M6 내보내기·GDS |

지도 아래 **경로 막대**가 단계별 완료(✓)와 **다음 권장** 버튼을 보여 줍니다. 경로를 바꿔도 진행 기록은 지워지지 않습니다.

## 3. 레벨 화면
| 영역 | 내용 |
|---|---|
| 미션 카드 | 레벨 설명, 개념 노트, 목표 ★ / ★★ / ★★★, ★ 뒤 **다음 레벨 →**, Engineering Review(일부 레벨), 1.6T 속도 정의(2-3·2-3R·3A·3A+·3W) |
| 화면 | 소자 그림, 점수, 핵심 수치 타일, 코치(다음 한 수), **바꾼 것 → 결과**(방금 바꾼 손잡이, 미션 지표 이전 → 현재, 물리적 이유, trade-off) |
| 설계 파라미터 | 슬라이더·−/+ (길게 누르면 연속, 방향키로 한 칸). 데스크톱에서는 오른쪽에 고정되어 화면과 함께 보입니다 |
| 하단 상태 바 (휴대폰) | 화면이 위로 사라지면 점수·별·코치 한 줄 |
| 비교 패널 | 2-3R: MZM vs MRR · 3A+: MZM ×8 vs MRR ×8 + **MRR 열 민감도** · 3W: DR8 vs WDM8 + **광학 모델 / 제어 구조 / 시스템 견고성**. 점수에 들어가지 않음 |
| 기준 설계와 비교 | 2-3R·3A+·3W: 지금 설계를 기준으로 고정 → 바꾼 설계와 나란히(Δ, 좋아짐/나빠짐, trade-off). **같은 웨이퍼로 수율 비교**(같은 시드, 크레딧·별 없음) |
| Fab Run | Tape-out(크레딧 사용) → 69 다이 Monte Carlo 수율. 시드·다이 수·95 % 구간·설계 hash·모델 버전이 기록되고, 시드를 고정하면 같은 웨이퍼로 다시 낼 수 있습니다 |
| Beat the AI · Design DB · 부품 카드 | 기존과 같음 |

근거 표시(◆ Analytical · ◇ Surrogate · ● Experimental · △ Assumption · ○ NOT VERIFIED)를 누르면 학습 가이드의 모델 한계(F)로 갑니다.

### 별과 점수
- ★ 기본 스펙 · ★★ 고성능 + 크기 · ★★★ Fab Run 수율 목표.
- Guided 학습 단계(1-7, 2-3R)는 별·카드·AI·Tape-out이 없는 연습이며, 마지막 단계(Full Design)에서 겨룹니다.
- Engineering Review, 비교 패널, 열 민감도, 같은 웨이퍼 비교는 **점수·별에 영향이 없습니다.**

## 4. PIC Design Lab
지도의 **LAB** 노드. 1.6T Tx PIC(DR8 MZM ×8 / DR8 MRR ×8 / WDM8 공유 버스 링 ×8)을 여섯 미션으로 설계합니다.
- 미션 칸의 ✓는 **지금 설계로** 충족한 것, **!**는 이전에 완료했지만 설계를 바꿔 지금은 충족하지 않는 것입니다.
- 검사 표의 FAIL/WARNING 행에서 **위치 보기** → 캔버스에서 관련 소자·넷·지점을 강조하고 Inspector에 원인과 고칠 손잡이, 해당 미션으로 가는 버튼을 보여 줍니다. 위치를 계산하지 않는 검사(금속 교차 등)는 관련 소자만 표시합니다.
- 레이어 표시(광·전기·검사 표시)는 보기 전용이며 GDS와 무관합니다. 휴대폰에서는 두 손가락으로 확대합니다.
- 상태 세 단계: **Design Valid**(게임 모델 충족) · **Geometry Rechecked**(만든 GDS를 다시 읽어 검사, design hash 일치) · **Foundry Readiness: NOT VERIFIED**.
- 같은 설계(design hash)로 돌아오면 이전 내보내기·GDS 재검사가 다시 유효해집니다. 검증 실행은 검사 결과까지 같을 때만 유효합니다.

### GDS (Advanced Workflow, 선택)
Mission 6에서 `smq-circuit/1` 세 파일을 내려받은 뒤, Python 환경에서:
```
pip install -r tools/smq2gds/requirements.txt     # gdsfactory, klayout …
cd tools && python -m smq2gds.circuit <플랫폼>_engine_layout.json -o gds/
```
→ `engine_layout.gds`, `engine_preview.png`, `engine_verification.json`. 그 verification 파일을 Mission 6의 “GDS 재검사 결과 불러오기”로 불러오면 Geometry Rechecked가 반영됩니다. 자세한 내용은 `docs/gds_export.md`.

## 5. 저장 · 백업 · 복원
- 진행 기록은 **이 브라우저의 localStorage에만** 있습니다. 브라우저 데이터 삭제, 다른 PC, 시크릿 창에서는 사라집니다.
- 머리글 오른쪽의 저장 표시: ● 저장됨 · 저장 중… · ■ **저장 실패**(빨강, 배너 표시 — 창을 닫으면 변경이 사라질 수 있음) · ○ **백업 권장**.
- 저장 표시를 누르면 **전체 백업**(`smq-backup/1`, 체크섬 포함)을 내려받거나 복사할 수 있습니다. 회사 브라우저가 파일 저장·클립보드를 막으면 JSON이 화면에 선택된 상태로 나오니 직접 복사해 보관하세요.
- **복원**: 백업 파일 선택 또는 JSON 붙여넣기 → 검사(형식·체크섬·구조) → 지금 데이터와 비교 요약 → 확인 체크 → 복원. 복원 직전 데이터는 자동 보관되어 “복원 되돌리기”가 가능합니다. 복원 중 저장이 거부되면 모든 데이터를 원래대로 되돌립니다.
- 설계 하나를 내보내는 `smq-design/1`(레벨)과 `smq-circuit/1`(Lab)은 백업이 아닙니다.

## 6. 접근성
- 모든 손잡이는 키보드로 조작됩니다(Tab, 방향키, Enter). 대화 상자는 Esc로 닫히고 초점이 원래 자리로 돌아갑니다.
- 상태는 색만이 아니라 글자·기호(✓ ✕ ! ◆ ◇ ● △ ○)로도 표시합니다. 캔버스 그림의 핵심 수치는 타일·표에 글자로 있습니다.
- 시스템의 "동작 줄이기" 설정을 따르며, 125–200 % 확대에서 레이아웃이 한 열로 바뀝니다.
