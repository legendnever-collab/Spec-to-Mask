# SPEC-to-MASK v2.0 P1 — User Guide

Open the offline HTML `spec-to-mask-v2.0.0-alpha.1-p1.html` in a modern browser. Choose Waveguide Tutorial from Engine Overview. Adjust Bend Radius and observe Physical View, Bend Radiation Loss, Propagation Loss, Total Arc Loss, and Footprint. Use Comparison / Original to compare or revert, and Learn Physics for optional details. Continue or Skip to the Summary. The tutorial is exploratory; it does not certify performance.

More provides Platform selection and Backup/Restore. Legacy Studio remains available. Technical terms are English and explanatory sentences are Korean.
