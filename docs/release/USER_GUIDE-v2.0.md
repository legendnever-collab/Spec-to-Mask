# P2.1 — User Guide

1. `spec-to-mask-v2.0.0-alpha.3-p2-ux.html`을 다운로드해 Browser에서 엽니다. 외부 Runtime / Font 다운로드가 필요하지 않습니다.
2. 신규 사용자는 Overview의 하나의 주요 버튼으로 Waveguide Tutorial을 시작합니다. Bend Radius를 움직이고 Loss / Footprint를 관찰합니다.
3. Summary에서 한 페이지 Roadmap을 연 뒤 Passive Basics를 시작합니다. Width / Mode → Splitter / Combiner → Path / Interference 순서로 조작합니다.
4. MZM Intro에서는 같은 Passive MZI에 PN Phase Shifter를 추가하고 Applied Electrode Vdiff로 Phase를 제어합니다. 기존 P2 Design은 덮어쓰지 않습니다.
5. MZM Interaction Length에서는 Accumulated Voltage-induced Phase / Vπ와 Optical Loss Plot을 봅니다. Electrode Length는 L, Active Length는 ηL입니다. Total Phase에는 Optical Bias도 포함됩니다.
6. Voltage & Interference에서는 두 Arm의 Phase와 Combiner 뒤 Output을 봅니다. RF/EO & PAM4 Eye에서는 Symbol Rate / Driver의 영향을 관찰합니다. 112 GBd PAM4는 224 Gb/s raw입니다.
7. Discover는 최적화 Gate 없이 Continue / Skip할 수 있습니다. 관찰 / unobserved / skipped 기록을 분리합니다. Engineer는 같은 Design에서 예시 Constraint를 추가합니다.
8. Comparison / Original을 복원할 수 있습니다. Solution Preview는 완료가 아니며 명시적으로 Apply하면 새 Revision에서 계산합니다. Learn Physics / Quick Glossary는 읽기 전용입니다.
9. Overview는 마지막 위치를 Resume합니다. More에서는 Tutorial / Passive / Intro / MZM 재방문, Platform 변경, Full Backup / Restore, Advanced / Legacy를 제공합니다. 기존 P1·P2 완료 기록과 Platform별 Workspace를 보존합니다.

다른 Browser / File로 옮길 때는 기존 파일의 More에서 Full Backup을 생성하고 새 파일에서 Restore 검사 → Restore 실행을 사용하세요. P2.1 Summary에서 사용자 Play Review를 진행합니다. P3 / main 병합은 하지 않습니다.
