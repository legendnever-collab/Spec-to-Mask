# P2 — User Guide

1. `spec-to-mask-v2.0.0-alpha.2-p2.html`을 다운로드해 Browser에서 엽니다. 외부 Runtime / Font 다운로드가 필요하지 않습니다.
2. 처음에는 Waveguide Tutorial을 사용할 수 있으며 **MZM Workbench 열기**로 P2에 들어갑니다. Waveguide Summary에서도 이어갈 수 있습니다.
3. Interaction Length를 움직여 PN Active Length, Vπ, Optical Loss를 비교합니다. 길이는 Electrode L이며 Active Length는 ηL입니다.
4. 계속하기로 Voltage & Interference에 들어가 Applied Electrode Vdiff와 Phase / Output Power / Transfer Curve를 관찰합니다.
5. RF/EO & PAM4 Eye에서 Symbol Rate를 20 → 112 GBd로 바꿉니다. Engineer에서 Driver Bandwidth / Source Vpp / Optical Phase Bias를 조정할 수 있습니다. Source Vpp와 Applied Electrode Vdiff는 서로 다른 조건입니다.
6. Engineer의 예시 Constraint는 성능 인증이 아닙니다. Discover에서는 최적값을 찾지 않아도 진행하며 조작 없는 Continue는 완료 관찰로 기록하지 않습니다.
7. Comparison 저장 / 복원과 Original 복원을 사용합니다. Solution은 Preview 후 명시적으로 Apply하며 Original을 보존합니다. Learn Physics는 읽기 전용입니다.
8. More에서 Platform / Full Backup / Restore / Advanced Legacy를 사용합니다. Platform별 P1 / P2 Workspace와 기존 Legacy를 따로 보존합니다.

P2 Summary에서 사용자 Play Review를 진행합니다. P3 Link Budget은 아직 제공하지 않습니다.
