# P2.1 Additional Learning Experience — User Guide

1. `spec-to-mask-v2.0.0-alpha.3-p21-learning.html`을 다운로드해 Browser에서 엽니다. 외부 Font / Script가 필요하지 않습니다.
2. Waveguide Tutorial에서 Bend Radius를 조작합니다. Summary 맨 아래에서 Passive Basics / MZM 학습 / Engine Overview를 선택합니다. MZM 선택은 Introduction부터 시작합니다.
3. Passive Basics는 Width / TE0·TE1 Mode → Bend → Y-branch → Directional Coupler / MMI 순서입니다. Field와 Optimization은 Conceptual 표시를 확인합니다. Course Dropdown에는 기존 Split Ratio / Path Experiment도 있습니다.
4. MZM Introduction은 Passive MZI → PN → Single-arm / Dual-arm → Transfer 순서입니다. 각 Arm의 ΔV / Reverse Bias / Phase를 비교합니다. 각 Arm의 Excursion과 Differential Voltage / Driver Vpp를 혼동하지 않습니다.
5. Summary에서 MZM Workbench로 이동합니다. Length는 같은 Voltage의 Phase / Vπ / Loss, Voltage는 Operating Point를 설명합니다. 다음 Formats에서 NRZ/PAM4/PAM8을 같은 Baud 또는 같은 Raw Rate로 비교합니다.
6. RF/EO Dynamic Eye는 기존 PN / MZM / Driver Model을 사용합니다. 112 GBd PAM4는 224 Gb/s raw입니다. Raw Eye Gap은 BER / FEC / Net 200G 검증이 아닙니다.
7. More의 Learning Navigation은 현재 Stage / 완료 Indicator / Stage Resume를 제공합니다. Workspace Settings에서 Platform / Advanced·Legacy를 열고 Full Backup / Restore를 펼칩니다. Backup 생성 → Restore 검사 → Restore 실행을 사용합니다.
8. Continue / Skip은 최적화 Gate가 없습니다. Skip은 완료된 관찰로 기록하지 않습니다. Learn Physics는 읽기 전용이며 Original / Comparison은 새 Revision에서 재계산합니다.
