# MZM bench beta guide

Open the single HTML. Select Si 1310 → MZM DR8 → Level 1. Complete the PN stage (Reference Apply is available in More), then Next to TW-MZM. Existing L / Gap / fill / RT controls affect the device. Additional Single-lane Bench controls below them set independent analytical experiments. Scroll Inspect to compare RF/EO, Smith, impedance and main/complementary transfer.

Current analysis can be exported as JSON. A blank or invalid bench field hides stale plots and blocks export. Track saves, reload, Text Backup and Snapshot include bench settings. Use More → Reference Apply / Original for device comparison, or the bench defaults button to reset only experimental conditions.

Bench conditions do not change the existing Canvas eye or Mission gate. The legacy 112 GBd PAM4 eye and its conditions remain explicitly separate. GDS export retains the existing Lab/Python workflow; analysis JSON is not GDS. Refer to the v1.1 guide for unchanged Studio, Save and Lab controls.
