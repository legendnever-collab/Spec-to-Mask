      Learning Guide · 원리 배우기

      모델 범위 — 게임이 계산하는 것, 단순화와 가정 (플랫폼·Stage 1–3·Track B·Design Lab·게임 밖 검증)

      플랫폼 · Stage 1. 플랫폼 4종(Si 220 nm / SiN 400 nm × 1310 / 1550 nm, SiO₂ 클래딩)의 모드는 semi-vectorial 2D 유한차분 솔버(quasi-TE Ex, quasi-TM Ey)로 사전계산한 테이블입니다: 도파로 TE/TM 모드와 neff(폭·두께·파장), 방향성 결합기의 짝/홀 슈퍼모드, SSC 팁 모드와 광섬유 overlap. MMI는 2D 유효굴절률법 + 고유모드 전개, CWDM은 같은 neff·ng 테이블로 만든 회로 S-matrix입니다. 측벽 산란 손실은 (∂neff/∂w)²에 비례하는 근사, 기판 누설은 BOX 터널링 근사. 반사, 3D 방사, 벤드 구간 결합, 편광 혼합은 포함하지 않아 FDTD·벡터 솔버보다 낙관적입니다 (500×220 nm Si @1550 TE0 neff 2.49 vs 벡터 해 ≈ 2.44).

      Stage 2. TO: 히터 단면 2D 유한체적 열해석 테이블(트렌치·언더컷; 언더컷은 2D에서 볼 수 없는 팔 끝·테더 누설 0.5 W/m·K를 더함) + EIM dneff/dT, τ는 국소 적층 에너지법. PN: 리브 EIM + 1D 모드, 계단 접합 공핍 근사, Soref–Bennett(1.31/1.55 µm), Caughey–Thomas 이동도. TW-MZM: CPW 등각사상(Hilberg) + 접합 부하 전신방정식, 양끝 반사, 광 진행 좌표계 적분, 112 GBd PAM4 눈은 5-tap FFE 기준 수신기(TDECQ 방식 근사, 잡음 증폭 √Σc²). Ge PD: 흡수 1−e−ΓαL, 전이(0.45v/d)×RC 1차 극, TIA 잡음은 입력 C에 비례하는 근사. 2-3R 링 변조기: Si 리브(220/90 nm) EIM, 결합은 휜 간격 위 Marcuse 결합 슬랩 κ 적분, 굽힘 방사 Marcuse, 링 손실 = 2-2 접합 흡수(덮개 75%) + 측벽 0.15 dB/mm + 히터 금속 + TPA·FCA. 투과는 all-pass Airy 식, 고속은 결합 모드 방정식(CMT) 시간영역 적분(광자 수명) × 접합 RC 극 — Q만으로 대역폭을 정하지 않습니다. OMA는 정착 레벨(정적, TDECQ 방식 점수)과 파형 극값(동적)을 분리합니다. 열: 2-1 단면 열해석의 G′를 링 둘레에 그대로 적용(링의 3D 열 퍼짐 무시 → 히터 효율 낙관적), 자기 가열 개루프 이득으로 빨강 쪽 디튜닝의 열 불안정을 판정. 공정: 폭·두께 산포로 공진 이동, 레이아웃 반경은 1 nm 격자에서 공진을 레이저 파장에 맞춘 값(GDS 반경과 같음). SiN 플랫폼의 링은 이종 집적 Si 활성층 가정입니다. MZM 비교의 구동 에너지는 부하 C·V²(PAM4) 대 정합 선로 V²/R이며 드라이버 효율·DSP는 포함하지 않습니다. 링크: 부품 카드의 대표값을 dB로 더한 버짓, 광 궤환은 파셋 Fresnel × 가우시안 overlap과 RIN 페널티 로지스틱 근사.

      Stage 3. 모듈 = 부품 카드(또는 기준 설계)의 대표값을 dB·W로 조립. 3A+의 링 변조기(MRR ×8): 레인 링마다 2-3R 엔진을 모듈의 변조기 입력 파워에서 다시 계산(0.5 dB 격자 보간), 히터 락으로 설계 디튜닝 유지, 히터 = (링 드리프트 − 레이저 드리프트)·ΔT mod FSR의 0–70 °C 최악값, 비냉각 DFB 0.085/0.10 nm/K·파장 산포 σ 0.5 nm·락 2 mW/레인·드라이버(= MZM 등급 − 부하 에너지 차)는 대표값 가정, 링 열 효율은 2D 단면 × 둘레라 낙관적(문헌 비교는 docs/arch_1p6t_dr8.md). 레인 마진은 4채널 × 케이스 0/70 °C 코너의 최솟값이며, Demux는 1-7 lattice를 dneff/dT만큼 굴절률을 옮겨 다시 계산(밴드 ±6.5 nm 최악). 비냉각 DFB: −0.02 dB/K(25 °C 이상), WPE −0.5%/K. TEC: 0.3 W + 레이저 발열/COP 0.6. 크로스토크 페널티 −10log(1−3·XT). 전력 상수(1.6T DSP 10 W, MLSE +1.5 W, 드라이버 0.35/0.15 W·레인, TIA 0.12 W·레인, DC-DC 90%)와 LPO/CPO 페널티(전기 +1.5/+0.5 dB, 감도 +0.5/+0.3 dB, CPO FAU +1 dB)는 학습용 대표값입니다.

      3W 링 WDM8. 한 버스의 링 8개는 2-3R 엔진(반경만 바꿈)의 all-pass Airy 투과를 곱해 통과 손실·변조 크로스토크(−10log(1−3ε))·FSR 별칭을 같은 식으로 계산하고, 히터는 빨강 쪽으로만 밀며 (목표 − 가열 전 공진) mod FSR, 배정은 고정 또는 순환(배럴 시프트, 온도마다 최소 전력), 열 결합은 2-1 2D 단면 프로파일(상한)입니다. 링 간 불일치 σ 0.15 nm, 콤 가장자리 −2 dB·WPE 12 %, DFB+MUX 2.5 dB, Rx Demux 1.5 dB·XT, 히터 범위 1.2·P2π는 가정입니다.

      긴 지연선. 단면은 EIM, 산란 손실은 σ²·(n₁²−n₂²)·∂neff/∂w(측벽)와 ∂neff/∂t(상하면)에 비례하는 근사로, 상수는 Hong 2022의 Si 측정값(0.45/1.6/2 µm: 5.5/0.38/0.28 dB/cm, σ 4.6/0.42 nm)에 한 번 맞춘 뒤 SiN(σ 5/0.4 nm 가정, 재료 흡수 0.06 dB/cm @1550, 0.02 @1310)에 그대로 적용합니다. 굽힘 방사는 EIM 횡방향 슬랩의 Marcuse 식이라 SiN 임계 반경을 실제보다 작게 예측하는 경향이 있습니다. S-bend 모드 변환은 n²w³/(λ²R) 스케일을 논문의 원호 −2.3 dB에 맞춘 근사, 이웃 회전 결합은 결합 슬랩 κ(동방향 가정, 보수적)입니다. MZ 스위치 위상 오차는 국소 폭 요동 2 nm·√(L·3 µm) 가정, 보정 후 잔차는 초기 오차의 15%로 둡니다. 직사각형 나선은 경계 안에 생성한 실제 형상(직선·원호/Euler 코너·중앙 S-bend)의 길이와 국소 반경으로 손실·지연을 계산하며, 원호 코너의 곡률 점프 모드 변환은 접합마다 가우시안 이동을 비간섭으로 더한 공학적 추정입니다. 1-7 Guided 단계의 MZI는 같은 neff·ng 테이블과 커플러 과잉손실 0.05 dB를 쓰며, 단계 3의 "출력 전력의 95%"는 과잉손실을 뺀 포트 분배 비율입니다.

      Track B. 처프: 분해능 c/2B, 비트 fb = 2Rγ/c ≤ ADC 500 MHz, 코히어런스 손실 exp(−2πΔν·2R/c), 잔류 처프 오차 √(지터² + Δν/(2πτrefM) + 측정²)로 비트 위상 오차 2π(2R/c)e → exp(−σφ²); 레이저 선폭·튜닝 범위·지터와 예왜곡 평균 M = 1000은 대표값 가정. 거리 눈금 오차 = R·(1/ng)dng/dT·ΔT. 스캐너: 가우시안 방출 모드 → 렌즈 뒤 wb = λf/(πwe), 퍼짐 we/f(FWHM 1.18배), 수차는 NA·시야각에 대한 경험식, 스위치 손실·소광비는 대표값(열광학 0.3 dB/−27 dB, PIN 0.9 dB/−19 dB). 시스템: 모노스태틱 코히어런트, 람베르트 ρ = 0.1, Prx = PoutρD²/(4R²)·ηhet(0.4, 스펙클), 왕복 칩 손실, 균형 검출 SNR = ℜPrxTint/q × 샷잡음 비율(TIA 10 pA/√Hz), 처프 Nav개 비코히어런트 적산 √Nav, 임계 13 dB; Si는 TPA/FCA 손실 0.6·(P/100 mW)² dB 근사. 도플러·다중 반사·눈 안전은 다루지 않습니다. 공정 변동: 웨이퍼 CD 오프셋 + 두께 bowl + 다이 랜덤(CD σ ≈ 8 nm, 두께 σ ≈ Si 3 nm / SiN 5 nm).

      PIC Design Lab. 부품은 카드 또는 기준 설계의 레벨 엔진 값, 배선은 직선·원호/Euler 코너·S-bend 기하로 길이·굽힘·간격을 계산하고, 전파 손실은 D-1 산란 모델, 테이퍼 길이·패드/범프 크기·MZM 접지 폭은 대표값 가정입니다. 시스템 예측은 3A+ 엔진 마진에서 레이아웃 배선 손실을 뺀 값이며, 금속은 RF(M1)·DC(M2) 각 한 층의 추상 선(폭 10/5 µm)으로 그려 같은 층 접촉만 검사합니다. RF 전자기·레인 간 열 크로스토크·파운드리 규칙은 검사하지 않습니다(NOT VERIFIED). GDS는 tools/smq2gds(circuit)가 같은 기본 도형으로 그리고 다시 읽어 검사합니다. 결과는 Engineering Prototype이며 Tape-out Ready가 아닙니다.

      게임 밖 검증. 설계 내보내기(smq-design/1) → tools/smq2gds가 GDS(gdsfactory)와 솔버 입력을 만듭니다. MMI는 GDS를 그대로 자른 3D EME(국소 Tidy3D FDE 모드, 테이퍼 포함), 지연 나선은 같은 단면의 벡터 모드 해석(직선: 두 격자 Richardson, 굽힘: PML·등각 변환)과 곡률 반전 모드 겹침으로 검사하고, 참조 설계의 결과를 "오프라인 솔버 검증" 패널에 게임 예측과 나란히 보여 줍니다. 각 보스의 최종 검증은 3D FDTD(MEEP 스크립트 생성, Tidy3D)·Ansys(CHARGE/HEAT/INTERCONNECT)로 넘기는 것을 전제로 합니다.
