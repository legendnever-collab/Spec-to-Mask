# smq2gds — 게임 설계를 마스크와 솔버로

게임에서 **설계 내보내기 (JSON)** 로 받은 `smq-design/1` 파일을 GDS와 시뮬레이션 입력으로 바꿉니다.
JSON이 계약(contract)이고 gdsfactory는 그 뒤에 붙는 백엔드 하나입니다 — IPKISS 백엔드도 같은 파일을 읽으면 됩니다.

```
게임 (surrogate) ──JSON──▶ smq2gds ──▶ GDS (+ PNG 미리보기)
                                  ├──▶ --sim mode : 단면·굽힘 검사 (Tidy3D 로컬 모드 솔버)
                                  ├──▶ --sim eme  : MMI 3D EME (GDS에서 바로 셀 분할)
                                  └──▶ --meep     : MEEP FDTD 스크립트 (GDS를 직접 읽음)
결과 ──▶ src/data/validation.json ──▶ 게임 "오프라인 솔버 검증" 패널
```

## 설치

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r tools/smq2gds/requirements.txt
```

모드 솔버와 EME는 Tidy3D의 **로컬** FDE 솔버만 씁니다 (계정·크레딧 불필요). MEEP는 conda-forge 패키지라 따로 받습니다
(`conda create -n mp -c conda-forge pymeep`). 생성된 MEEP 스크립트는 gdsfactory 없이 GDS만 읽습니다.

## 사용

`tools/`에서 실행합니다.

```bash
python -m smq2gds smq_si1310_1-5.json -o mmi.gds --png mmi.png        # GDS + 미리보기
python -m smq2gds smq_si1310_1-5.json -o mmi.gds --sim eme             # 3D EME (λ마다 ~3분, 2 CPU)
python -m smq2gds smq_si1550_D-1.json -o spiral.gds --sim mode         # 단면·굽힘·S-bend 검사 (~2분)
python -m smq2gds smq_si1310_1-5.json -o mmi.gds --meep mmi_meep.py    # MEEP 스크립트
conda activate mp && python mmi_meep.py --gds mmi.gds [--2d] [--res 20]
python -m smq2gds.validate --levels 1-3,1-4,1-5,D-1                   # 참조 설계 검증 → src/data/validation.json
python -m smq2gds.fit_sbend                                            # S-bend 곡률 반전 변환 스윕
```

`examples/`는 각 플랫폼·레벨의 보정된 참조 설계를 게임에서 내보낸 파일입니다 (`node test/e2e/export.js all`로 다시 만듭니다).

## PCell

| pcell | 형상 | 게임과의 대응 |
|---|---|---|
| `mmi` | gdsfactory `mmi1x2` / `mmi2x2`, w₀ → wₜ 선형 테이퍼 (Si 10 µm, SiN 30 µm) | W, L, wₜ, s 그대로. 게임은 테이퍼를 단열로 가정하므로 테이퍼 손실은 솔버에서만 보입니다 |
| `spiral` | 이중 아르키메데스 나선 r = r_in + (p/π)θ (두 팔이 맞물려 도파로 간격 p), 중앙 S-bend, 바깥 끝 w → w₀ 테이퍼 | 경로 길이 = 게임의 L (팔 + S-bend), r_out 일치 (< 0.1 %) |

S-bend
- **arc**: 두 원호. 끝점에서 나선의 접선과 맞도록 반경을 풉니다 (≈ r_in/2).
- **euler**: 곡률이 중앙의 1/R_min에서 접합부의 나선 곡률까지 선형으로 줄어드는 클로소이드 두 개 (Hong 2022 방식).
  - 접합부에서 곡률까지 연속이고, 폭은 중앙의 W_s에서 W까지 테이퍼됩니다.
  - R_min은 끝점 조건에서 풀려 나오며 ≈ 0.37–0.38·r_in입니다. 게임은 r_in/2.5 = 0.4·r_in으로 둡니다.

폴리곤은 꼭짓점 ≤ 3982개로 나눠 GDS 레코드가 32 KB를 넘지 않게 하고, 법선은 호 길이 기준 2차 차분으로 구해 이음매에 노치가 생기지 않게 합니다.
`test/py/test_smq2gds.py`가 모든 예제에 대해 다음을 확인합니다.
- 도파로가 한 덩어리인지
- 폭·간격 DRC
- 길이와 r_out
- 출력 포트 위치

## 솔버 검사의 범위

- **직선 단면**: Tidy3D 로컬 FDE에는 sub-pixel 평균이 없어 계단 오차가 O(dl)입니다. 두 격자(Si 20/10 nm)의 Richardson 외삽으로 지웁니다.
  - 500×220 nm Si @1550 TE0 2.444, TM0 1.769로 문헌값과 맞습니다.
- **굽힘**: PML과 등각 변환을 쓰고, 손실 계산 영역은 방사 caustic 너머까지 잡습니다.
  - 곡률 반전 변환은 +R/−R 기본 모드의 겹침 1 − |⟨E₊|E₋⟩|²입니다. 접합이 급격하다고 가정합니다.
- **EME**: GDS를 x 방향 셀(테이퍼당 16, 본체 1)로 자르고 모든 셀을 같은 y–z 격자에서 풉니다.
  - 순방향 EME라 반사를 무시합니다.
  - 포트 전력은 고립된 출력 도파로 TE0에 투영해서 구합니다.
  - 균일 격자라 좁은 포트의 n_eff에는 ~1 % 오차가 남고, 넓은 본체의 맥놀이 길이는 더 정확합니다.
  - 테이퍼 셀·모드 수를 8/22 → 16/30 → 24/36으로 늘려 수렴을 확인했습니다 (결과는 validation.json).
- **MEEP 스크립트**: GDS를 `mp.get_GDSII_prisms`로 읽는 3D(또는 `--2d` 슬래브 EIM) FDTD입니다.
  - 이 저장소의 실행 환경에는 conda-forge가 막혀 있어, 스텁 meep 모듈로 스크립트 로직만 검사했습니다.

게임의 2D EIM MMI는 결상 길이를 길게 잡습니다. Si는 10–20 %, SiN은 5–8 % 깁니다. 고대비일수록 차이가 커서 EIM의 한계와 맞는 경향입니다.
3D 최적 L에서의 EL(0.1–0.85 dB)에는 게임이 단열로 가정한 테이퍼 손실이 들어 있습니다.
다음 보정 후보는 MMI 본체 TE 모드의 β를 폭·파장 테이블로 미리 계산해 EIM 측방 해를 대체하는 것입니다. 현재 `wg_*.json`과 같은 방식입니다.

| 플랫폼 | n_g 게임 → 솔버 | ∂n_eff/∂w 게임 → 솔버 | S-bend 변환 게임 → 솔버 (dB) | IL 게임 → 솔버 보정 (dB) |
|---|---|---|---|---|
| si1310 | 3.831 → 3.832 | 0.0138 → 0.0112 | -25.1 → -25.4 | 4.23 → 4.05 |
| si1550 | 3.718 → 3.720 | 0.0163 → 0.0169 | -24.5 → -24.2 | 4.13 → 4.15 |
| sin1310 | 2.067 → 2.069 | 0.0108 → 0.0116 | -25.4 → -25.1 | 1.11 → 1.12 |
| sin1550 | 2.038 → 2.042 | 0.0141 → 0.0156 | -26.1 → -23.4 | 2.30 → 2.33 |

S-bend 곡률 반전 변환은 원래 논문 원호 결과 하나에 맞춘 상수(K 0.377, Euler는 R = r_in에서 평가)였습니다.
`fit_sbend.py` 스윕(22점)으로 다시 맞췄습니다.
- 새 모델: a = K·n_s²·(w + c·2/γ)³/(λ²R), 중앙 R_min에서 평가합니다.
- 상수: Si는 K 0.80, c 0 (rms 0.5 dB), SiN은 K 0.633, c 1.05 (rms 0.24 dB)입니다.
- 같은 설계라면 Si에서 약 15 dB 비관적입니다. D-1/D-2와 Track B는 `calibrate.js all 4,5`로 다시 보정했고, 참조 설계는 r_in이 커지고 W_s가 좁아졌습니다.
- SiN 1550의 2.7 dB 차이는 스윕 범위(w ≥ 1.2 µm) 밖의 W_s = 0.8 µm에서 생긴 것입니다.
